  • Sizes are written as font size / line height in px. Set them in rem so the layout follows browser text zoom up to 200 %.
  • Nothing is smaller than 13 px. On phone, body text and inputs are 16 px, which also stops iOS from zooming into focused fields.
  • Tables, amounts and times use tabular numerals so digits line up in columns.
  • Heading levels follow the page structure: one h1 per page, h2 for sections and for drawer and dialog titles, h3 inside them.
  • No all-caps labels and no italics. Emphasis comes from weight.
